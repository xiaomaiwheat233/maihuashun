# 麦花顺

React + TypeScript + Vite 构建的纯前端手机端模拟炒股游戏。顶部可一键切换 A 股、港股和美股；当前三个市场均运行本地模拟行情。交易和账户始终只在浏览器内模拟，数据保存在当前浏览器的 `localStorage`。实时行情接入调研见 [REALTIME_MARKET_RESEARCH.md](REALTIME_MARKET_RESEARCH.md)。

## 运行

Windows 用户可双击项目根目录的 `一键启动.bat`。脚本会在需要时安装依赖、启动开发服务器，并在就绪后打开浏览器；保持命令窗口开启即可继续访问。

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址。生产构建运行 `npm run build`，交易规则测试运行 `npm test`，浏览器交互检查运行 `npm run test:e2e`（需安装 Chrome）。

股票目录已随项目打包，无需联网即可启动。需要人工更新静态目录时运行 `npm run refresh:universe`；来源、许可和历史价格日期见 [DATA_SOURCES.md](DATA_SOURCES.md)。

## 功能

- A 股静态目录包含 5,499 只股票，支持沪市主板、深市主板、创业板、科创板、北交所筛选；港股和美股各有 20 个常见证券标识示例，价格起点为人为设置的**模拟值**，并非对应日期的真实价格。三个市场均支持搜索、行业筛选、排序、自选和个股详情。来源与使用条件见 [DATA_SOURCES.md](DATA_SOURCES.md)。
- 顶部切换器会同时切换涨跌颜色：A 股红涨绿跌；港股、美股绿涨红跌。报价、分时/K 线、交易按钮、盈亏颜色使用同一市场配色。每个市场独立保存模拟资金、持仓、自选、委托和模拟时钟；分别以 CNY、HKD、USD 计价，不进行汇率换算。
- 3,149 只股票以 2026-03-03 历史收盘价为模拟起点；其他股票使用可复现的算法价格。此后所有价格、涨跌幅、成交量额和日/周/月 K 线均为游戏模拟。行情按大盘、行业及个股因子联动，分时、K 线与最新价使用同一份状态。
- 代码中保留了基于 [Miao API 股票接口](https://api.miao.club/docs/stock) 的真实行情适配器，但当前版本隐藏了模式入口，启动后进入离线模拟。接入条件与 2026-11-17 的实测结果见 [实时行情调研](REALTIME_MARKET_RESEARCH.md)。
- Miao 股票接口没有文档化 K 线或五档盘口；真实模式没有数据时显示“不可用”，不会展示虚构图表。分时图只绘制本机运行期间采到的真实报价快照，不能代替完整逐分钟走势。
- 预留的真实行情代码具有 8 秒超时、并发去重和缓存：报价 15 分钟、搜索 1 小时；当前没有前端入口触发这些请求。
- 真实报价和离线模拟分别拥有账户与自选，避免两个价格体系混算。
- 模拟行情每 3.5 秒推进一个市场交易分钟，可暂停、恢复或跳到下一个交易日。市场开闭市时段只是游戏时钟，不代表真实交易所日历或夏令时。
- 初始资金 100,000 元。支持买入、卖出、限价委托、撤单、持仓、资金冻结、委托和成交记录。
- 简化 A 股规则：100 股整数倍、主板 ±10% / 创业板和科创板 ±20% / 北交所 ±30% / ST ±5% 价格限制、当日买入次交易日可卖。费用为每笔最低 5 元的简化佣金，卖出另加 0.05% 模拟印花税。
- 港股按示例股票各自预设的模拟手数交易，游戏费用为最低 HK$3 或成交额的 0.1%；美股按 1 股交易，游戏内暂不收手续费。港美股不设游戏涨跌幅限制，允许当日模拟卖出。这些都是玩法规则，并非完整的真实市场收费、清算或交易制度。
- 账户、自选及当前行情在浏览器刷新后保留，可在“我的”中重置。

`src/core/liveMarket.ts` 定义真实报价适配器、字段转换、请求缓存与错误处理；`src/core/market.ts` 负责静态股票目录和离线模拟；`src/core/rules.ts` 定义可替换的交易规则接口；`src/core/store.tsx` 管理账户与紧凑持久化。特殊玩法可以另外实现 `TradingRules`。

### 数据源限制

Miao 文档说明允许浏览器跨域直接调用且不应把私密 API Key 放在前端。2026-11-17 本机对 `api.miao.club` 的 TLS 连接仍被重置，**未能验证其实际报价响应**。接口每日免费额度、数据时效和可用性受提供方约束。

东方财富 `push2` / `push2his` 在本机实测可返回报价与 K 线，并对本地页面 Origin 返回 CORS 许可，但其[服务协议](https://about.eastmoney.com/home/protocol)对行情数据复制与提供设有限制。因此该适配器默认禁用。仅在获得相应使用授权后，才可在构建时设置 `VITE_ENABLE_EASTMONEY=true` 使用。腾讯财经接口虽可响应，但缺少可确认的第三方网页展示许可，当前不启用。没有任何后端代理或浏览器中的私密 Key。
